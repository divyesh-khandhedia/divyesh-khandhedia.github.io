Power System Workbench

Run studies, inspect records and generate simulator scripts in your browser.

Two-bus QV curve

Sweep receiving-bus voltage at constant active load. Positive Q is load absorption.

Assumptions

Fixed source behind R + jX. The plot follows the larger reactive-load solution of the receiving-bus power equation. The peak is estimated from the selected voltage sweep. Generator limits and controls are outside this model.

Cable pulling tension

Estimate tension and sidewall pressure for a single cable on a level route.

Assumptions

Straights add μwL. Bends use the capstan equation and estimate peak sidewall pressure as exit tension divided by bend radius. Compare with cable manufacturer limits for your installation.

COMTRADE viewer

Open paired CFG and DAT files. Data stays in your browser.

Supported records

ASCII, BINARY, BINARY32 and FLOAT32 DAT formats with paired CFG. View one analog or digital channel at a time. DAT limit is 12 MiB. Analog values follow the CFG scale and offset without primary/secondary conversion.

Hourly unit commitment

Minimize dispatch, no-load and startup costs for up to seven generators and 48 hours.

Assumptions

All units start offline. Includes one-hour dispatch intervals, minimum and maximum output, and fixed startup costs. Omits network flows, reserves, ramping, and minimum on/off times. An online unit at zero MW is marked “On”.

PowerFactory Python builder

Generate a load-flow script that prints terminal voltage magnitudes in per unit.

Local requirements

Run with the matching PowerFactory Python API and a licensed installation. The builder generates source code in your browser.

PSCAD Python builder

Generate a PSCAD V5 script to launch PSCAD, load a workspace or case, and run a project.

Local requirements

Run on Windows with licensed PSCAD V5 and the installed mhi.pscad Automation Library. The script runs one project. Simulation sets and PMR are outside this template.
